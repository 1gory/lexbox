# Lexbox v1 — дизайн

**Дата:** 2026-10-07
**Статус:** утверждён, готов к планированию

## Цель

Chrome-расширение для изучения английских слов в контексте. Пользователь читает статью,
выделяет незнакомое слово или фразу и сохраняет их с переводом. При повторном чтении все
сохранённые выражения подсвечиваются на странице, а при наведении показывается перевод.
Статья становится «прозрачной», и слова запоминаются в контексте.

Целевой канал — Chrome Web Store (публичный продукт). Версия v1 работает **без бэкенда**.

## Объём v1

**Входит:**
- сохранение выделенного слова или фразы с переводом и контекстом;
- автоматический перевод через встроенный Chrome Translator API с правкой вручную;
- подсветка сохранённых выражений на любых страницах с учётом словоформ;
- тултип с переводом при наведении;
- popup и отдельная страница словаря (поиск, правка, удаление, импорт/экспорт, настройки);
- интерфейс на английском и русском (`chrome.i18n`).

**Не входит (следующие версии):** разбор фразы на фразовые глаголы и идиомы, бэкенд,
синхронизация между устройствами, интервальные повторения, side panel, Firefox, PDF, iframe.

## Стек

- **WXT** (Manifest V3) + **TypeScript** + **Preact**.
- Интерфейс на страницах сайтов рендерится внутри Shadow DOM.
- **Vitest** для unit-тестов, **Playwright** для e2e с загруженным расширением.

## Архитектура

```
lexbox/
├─ entrypoints/
│  ├─ content/        content script: выделение, плавающая кнопка, карточка, подсветка, тултип
│  ├─ background.ts   service worker: контекстное меню, горячая клавиша, маршрутизация сообщений
│  ├─ popup/          переключатели подсветки, счётчик, последние слова, «Открыть словарь»
│  └─ dictionary/     страница словаря (отдельная вкладка) + настройки
└─ lib/               чистый TS без chrome.* (кроме store.ts/translator.ts), покрыт unit-тестами
   ├─ morphology.ts   слово → множество возможных форм
   ├─ matcher.ts      индекс словаря и поиск совпадений в тексте
   ├─ context.ts      извлечение предложения вокруг выделения
   ├─ translator.ts   обёртка над Chrome Translator API
   └─ store.ts        CRUD поверх chrome.storage.local, слияние контекстов
```

### Границы модулей

| Модуль | Что делает | Зависимости |
|---|---|---|
| `morphology` | `forms(word): Set<string>` — все формы слова в нижнем регистре | таблица неправильных глаголов |
| `matcher` | `buildIndex(entries)`, `findMatches(index, text): Match[]` (`{start, end, entryId}`) | `morphology` |
| `context` | `extractSentence(blockText, start, end): string` | — |
| `translator` | `translate(text, target): Promise<TranslateResult>`, `status()` | `Translator` global |
| `store` | `list()`, `get(id)`, `findByText(text)`, `save(draft)`, `update()`, `remove()`, `import()`, `export()`, `subscribe(cb)` | `chrome.storage.local`, `matcher` |

### Разрешения манифеста

`storage`, `unlimitedStorage`, `contextMenus`; host permissions `<all_urls>`, потому что
подсветка работает на любых сайтах. Команда `save-selection` с подсказанной клавишей
`Alt+S` (переназначается в `chrome://extensions/shortcuts`). Content script подключается
только в основном фрейме (`all_frames: false`).

## Модель данных

```ts
interface Entry {
  id: string;            // crypto.randomUUID()
  text: string;          // как сохранили: "put up with"
  key: string;           // нормализованный текст: lowercase, схлопнутые пробелы,
                         // без пунктуации по краям
  translation: string;
  contexts: Context[];   // новые сверху
  createdAt: number;
  updatedAt: number;
}

interface Context {
  sentence: string;
  url: string;
  title: string;
  addedAt: number;
}

interface Settings {
  highlightEnabled: boolean;   // по умолчанию true
  floatingButton: boolean;     // по умолчанию true
  targetLang: string | null;   // по умолчанию язык интерфейса браузера; null, если он английский
  excludedSites: string[];     // hostnames
}
```

**Хранение:** `chrome.storage.local`, каждая запись лежит под своим ключом `entry:<id>`,
настройки под ключом `settings`.

**Дедупликация.** Перед сохранением выражение прогоняется через `matcher` по текущему
индексу. Если оно совпадает с существующей записью целиком (с учётом форм: сохраняем
«running», а в словаре есть «run»), новая запись не создаётся: в найденную добавляется
контекст. Контекст с тем же `url` и тем же `sentence` повторно не добавляется.

## Морфология

Формы генерируются **от сохранённого слова** (прямая генерация), а не через стемминг текста:

- исходное слово;
- `-s`, `-es` (после s, x, z, ch, sh, o), `y → ies` (после согласной);
- `-ed`, `-d` (если оканчивается на e), `y → ied`, удвоение конечной согласной (`stop → stopped`);
- `-ing`, отбрасывание конечной `e` (`make → making`), `ie → ying` (`lie → lying`), удвоение согласной;
- `-er`, `-est` (с теми же правилами для e/y/удвоения), `-ly`;
- неправильные глаголы: встроенная таблица примерно из 200 глаголов (base, past, participle).
  Если сохранённое слово есть в таблице в любой форме, в набор добавляется вся группа.

Лишние формы допустимы: они ни на что не влияют, пока не встретятся в тексте.

**Фразы:** каждый токен фразы раскрывается в свои формы, и фраза совпадает, если все токены
идут подряд и каждый попадает в своё множество форм (`put up with` → `putting up with`).

## Сценарии

### Сохранение

1. **Выделение.** Подходит выделение длиной 1–100 символов в пределах одного блока, вне
   `input`, `textarea` и `contenteditable`. Рядом с концом выделения появляется иконка
   (если `floatingButton` включён). Она исчезает при прокрутке, клике мимо и снятии выделения.
2. **Открытие карточки:** клик по иконке, `Alt+S` или пункт контекстного меню
   «Добавить в Lexbox». Последние два варианта идут через background, который отправляет
   сообщение `open-save-card` в content script активной вкладки.
3. **Карточка** (Shadow DOM, рядом с выделением):
   - выражение (редактируемое поле);
   - перевод: спиннер, затем результат `translator`; поле редактируемое;
   - предложение-контекст (только чтение, серым);
   - «Сохранить» (`Enter`), «Отмена» (`Esc`).
4. **Выражение уже в словаре:** карточка показывает сохранённый перевод (редактируемый),
   пометку «в словаре · N контекстов» и кнопку «Добавить контекст».

Контекст — это предложение, которое `context.extractSentence` вырезает из текста блочного
предка выделения. Границы предложения: `.`, `!`, `?`, за которыми идёт пробел и заглавная
буква или конец блока. Длина ограничена 300 символами с многоточием.

### Подсветка

- Реализована через **CSS Custom Highlight API** (`CSS.highlights.set('lexbox', highlight)`),
  DOM сайта не меняется.
- Стиль `::highlight(lexbox)`: светлый полупрозрачный фон и пунктирное подчёркивание,
  цвет текста не меняется.
- Обход: блочные элементы (`p`, `li`, `h1–h6`, `td`, `th`, `blockquote`, `dd`, `dt`, `figcaption`,
  а также `div` без блочных потомков). Текстовые узлы блока склеиваются в строку,
  `matcher.findMatches` возвращает смещения, они переводятся обратно в `Range`.
- Пропускаются `script`, `style`, `noscript`, `input`, `textarea`, `contenteditable`
  и собственный UI расширения.
- При пересечении совпадений побеждает самое длинное.
- Обработка идёт порциями в `requestIdleCallback`. `MutationObserver` с debounce 300 мс
  обрабатывает только изменённые блоки.
- По `storage.onChanged` индекс пересобирается и подсветка обновляется во всех вкладках.
- Подсветка выключена, если `highlightEnabled === false` или хост есть в `excludedSites`.

### Hover

По `mousemove` (с троттлингом) вызывается `document.caretPositionFromPoint`, и проверяется,
попала ли позиция в один из подсвеченных `Range`. Через 150 мс над совпадением появляется
тултип (Shadow DOM) с выражением и переводом. Тултип скрывается, когда курсор уходит.

### Popup

- Глобальный переключатель подсветки.
- Переключатель «Отключить на этом сайте» (добавляет или убирает хост из `excludedSites`).
- Число слов в словаре и 5 последних.
- Кнопка «Открыть словарь».
- На страницах, где content script не работает (`chrome://`, Web Store, PDF), выводится
  «На этой странице недоступно».

### Страница словаря

- Список, новые сверху; поиск по выражению и переводу.
- Правка перевода на месте, удаление с подтверждением.
- Раскрывающийся список контекстов: предложение (выражение в нём выделено)
  и ссылка на статью.
- Экспорт и импорт **JSON** (полный бэкап; при импорте записи сливаются по `key`, контексты
  объединяются с дедупликацией). Экспорт **CSV** (`text, translation, sentence`) для Anki.
- Раздел «Настройки»: плавающая кнопка, язык перевода, список исключённых сайтов.

## Перевод

- `translator.ts` проверяет `'Translator' in self` и `Translator.availability({sourceLanguage: 'en', targetLanguage})`.
- Экземпляр переводчика кэшируется на языковую пару.
- `Translator.create()` вызывается после действия пользователя (открытия карточки), потому что
  загрузка языкового пакета требует user activation. Пока пакет загружается, показывается статус
  «загрузка переводчика…», поле перевода остаётся редактируемым.
- Если `targetLang === null`, автоперевод не выполняется. Карточка показывает ссылку
  «выберите язык перевода» на настройки.

## Ошибки и ограничения

| Ситуация | Поведение |
|---|---|
| Translator API недоступен | Поле перевода пустое, подсказка «введите перевод» |
| Языковой пакет загружается | Статус «загрузка переводчика…», поле редактируемое |
| Ошибка перевода | Как при недоступном API, без всплывающих ошибок |
| `chrome://`, Web Store, PDF | Content script не работает, пункт меню неактивен, popup сообщает |
| iframe | Не поддерживается в v1 |
| Пустой перевод при сохранении | Разрешено; в словаре запись помечена «без перевода» |
| Битый файл импорта | Сообщение об ошибке, данные не меняются |

## Тестирование

**Vitest (`lib/`):**
- `morphology`: `stop → stopping/stopped`, `make → making`, `city → cities`, `lie → lying`,
  `run → ran/running`, обратная группа (`ran` даёт `run`).
- `matcher`: одно слово, фраза, фраза в разных формах, приоритет длинного совпадения,
  отсутствие совпадения внутри слова (`run` не находится в `rerun`), регистр.
- `context`: границы предложения, обрезка до 300 символов, выделение на краю блока.
- `store`: создание, дедупликация через формы, слияние контекстов, импорт/экспорт.

**Playwright (расширение загружено, Translator API заменён заглушкой):**
- выделить слово на локальной тестовой странице → иконка → карточка → сохранить;
- слово подсвечено (проверка через `CSS.highlights`), тултип показывает перевод;
- повторное сохранение того же слова из другого предложения добавляет контекст;
- фраза, разбитая тегом `<em>`, подсвечивается;
- выключенная подсветка и исключённый сайт отключают подсветку.
